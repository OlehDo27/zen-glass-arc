# Glass Arc

Frosted-glass sidebar with a gradient tint and sheen, a Nova-style icon strip
in compact mode, Nova-style buttons and tabs, a glass floating address bar and
a glass AI side panel (Ctrl+Alt+X).

Surface style (frosted glass, smoked glass, solid like Firefox Nova, stock Zen):
right click on the sidebar -> Edit Theme, or Settings -> Zen Mods -> Glass Arc.
