# Glass Arc для Zen Browser

Zen в стиле Arc / Firefox Nova:

- **Стекло вокруг страницы** — матовое, затемнённое, непрозрачное как в Nova или стандартный Zen. Переключается правым кликом по боковой панели → **Edit Theme**, там же, где цвета пространства.
- **Полоска иконок как в Nova** — кнопка ◫ сворачивает боковую панель в полоску, при наведении она выезжает, а страница плавно отъезжает в сторону. Essentials сеткой сверху, папки и разделённые вкладки блоками, звук на вкладке можно выключить кликом по значку.
- **Адресная строка сверху**, компактная, с кнопкой «скопировать ссылку», при вводе всплывает по центру, как в Arc.
- **AI-панель** (Ctrl+Alt+X) справа, стеклянной карточкой, ChatGPT по умолчанию.
- **«Загрузки» вместо «Библиотеки»** внизу боковой панели.
- Аппаратное декодирование видео и бережнее к памяти.

## Установка

Установщик сам поставит Zen, если его нет, и применит всё к профилю. Перед изменениями он делает резервную копию в `<профиль>/glass-arc-backup/`.

**Linux** (Arch/AUR, Flatpak или официальный tarball):

```bash
curl -fsSL https://raw.githubusercontent.com/OlehDo27/zen-glass-arc/main/install.sh | bash
```

**Windows** (PowerShell; Zen ставится через winget):

```powershell
irm https://raw.githubusercontent.com/OlehDo27/zen-glass-arc/main/install.ps1 | iex
```

Если Zen открыт, установщик попросит его закрыть. Для переключателя стиля в Edit Theme он кладёт маленький загрузчик `config.js` в папку Zen — на Linux для этого спросит `sudo`, на Windows права администратора. Можно отказаться: тогда стиль выбирается в **Настройки → Zen Mods → Glass Arc**.

Обновление — запустить установщик ещё раз. Ваши настройки мода (стиль, оттенок, ширина полосы) при этом не сбрасываются.

## Стили поверхности

| Стиль | Как выглядит |
| --- | --- |
| Матовое | Рабочий стол просвечивает через молочную дымку с градиентным оттенком |
| Тёмное | То же стекло, но затемнённое, как тонированное |
| Сплошное | Без прозрачности, ровный фон как в Firefox Nova, лёгкий намёк на оттенок |
| Zen | Стекло мода выключено, Zen рисует свой обычный фон |

Остальное (оттенок, матовость, размытие, ширина полосы, кнопки в стиле Nova, AI-панель) — в **Настройки → Zen Mods → Glass Arc**.

Чтобы стекло было именно матовым, а не просто прозрачным, размывать фон должна система:

- **Hyprland / KDE** размывают сами. На Hyprland стоит добавить правило из [`extras/hyprland.conf`](extras/hyprland.conf), чтобы страницы и видео никогда не просвечивали.
- **GNOME** не размывает фон — там лучше стиль «Тёмное» или «Сплошное».
- **Windows 11** — размытие Acrylic включается установщиком. На Windows 10 его нет, там лучше «Сплошное».

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/OlehDo27/zen-glass-arc/main/install.sh | bash -s -- --uninstall
```

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/OlehDo27/zen-glass-arc/main/install.ps1))) -Uninstall
```

Мод, загрузчик и правки `userChrome.css` убираются. Настройки Zen остаются как есть; прежний `prefs.js` лежит в резервной копии.

## Что внутри

| Путь | Что это |
| --- | --- |
| `mod/local-glass-arc/` | Сам мод Zen: `chrome.css` и его настройки |
| `profile/userChrome.css` | Компактная шапка AI-панели |
| `profile/JS/glassarc-style.uc.js` | Переключатель стиля в Edit Theme, перенос «Загрузок» |
| `loader/` | `config.js`, который запускает скрипты из `chrome/JS` профиля |
| `prefs/` | Настройки Zen: общие и для каждой системы |
| `tools/setup_profile.py` | Шаги установки в профиль (Linux) |
